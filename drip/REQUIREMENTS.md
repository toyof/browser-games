# Drip Line 要件定義

元ネタのジャンル: Happy Glass(線を描いて水をコップへ導く)。名前・見た目・ステージは自作。

## 位置づけ
- `drip/index.html`(静的HTML単体)。物理エンジンは Matter.js 0.19.0 を cdnjs から読み込む(suika と同じ)
- 保存: `dripBest` / `dripCur` / `dripMute`

## ルール
| 項目 | 内容 |
|---|---|
| 操作 | 1本の線を指でなぞって描く。指を離すと蛇口から水滴100個が出る |
| 線 | 描いた線はそのまま**剛体になって落ちる**(重力・摩擦あり)。板・釘・カップのふちに引っかけて使う |
| 描けない場所 | 板・釘・カップの中や蛇口の口。そこに入るとそれ以上は伸びない(赤く表示) |
| インク | 線の長さには上限がある。使ったインクが60%以下なら★3、85%以下なら★2 |
| クリア | カップに入った水滴が規定数以上の状態が約0.8秒続く |
| 失敗 | 全部の水滴が出たあと、動きが止まるか16秒たっても規定数に届かない |
| 補助 | やり直し / ヒント(想定解の線を点線で表示) |

## ステージ
- **手作り10ステージ**。各ステージに想定解の線(`sol`)を持たせ、ヒント表示と自動テストに使う
- 検証済みの条件: 想定解ならクリアする/線を描かないと失敗する(Playwright でシミュレーションして確認)

## 物理の調整メモ
- 描いた線は細い長方形を**線の太さぶん重ねて**つないだ複合体にする。継ぎ目があると釘がはまり、線がすり抜ける
- 摩擦はパーツ単位で計算されるので、線の各パーツに摩擦と密度を設定する。線を重くし(密度0.02)、水に押し流されないようにする
- 水滴は 1/120 秒刻みで2回計算し、速度に上限(5)を付ける。細い線をすり抜けないようにするため
- 水滴は摩擦0、空気抵抗0.015。摩擦があると砂のように斜面に溜まり、空気抵抗が強いと緩い斜面で詰まる
