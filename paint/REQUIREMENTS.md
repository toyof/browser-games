# Doodle Lab 要件定義

確認済みの方針: **本格派 / お題モード付き / PNG書き出し / PC優先**

## 位置づけ
- `browser_games/paint/index.html` (静的HTML単体、ビルド不要)
- ポータルにカード追加(🎨 Doodle Lab)、戻るボタン `assets/back-button.js` を読込
- ポータルのバッジ: お題チャレンジ完了数(localStorage `doodleDone`)

## 機能要件
| 区分 | 内容 |
|---|---|
| ツール | ペン / 消しゴム / 塗りつぶし / スポイト / 直線 / 四角 / 楕円 / 範囲選択(移動・拡縮・削除) |
| ブラシ | ペン・マーカー・エアブラシ・鉛筆・カリグラフィ(5種)。サイズ/不透明度/手ブレ補正/筆圧ON-OFF |
| 色 | HSV ピッカー、HEX入力、スウォッチ、履歴、描画色/背景色の入替(X) |
| レイヤー | 追加/複製/削除/結合/並べ替え/表示切替/不透明度/ブレンド(通常・乗算・スクリーン・オーバーレイ・比較暗/明)/名前変更/左右・上下反転 |
| 編集 | Undo/Redo(40段階)、ズーム、回転、パン、全体表示 |
| 塗りつぶし | 許容値、全レイヤー参照、境界拡張(隙間対策) |
| タイムラプス | 操作ごとに縮小フレームを記録し、再生ウィンドウで再生 |
| お題モード | お題ランダム抽選 + 制限時間(なし/1/3/5/10分)。時間切れ or「完成」で結果表示→PNG保存 |
| 保存 | PNG書き出し(Ctrl+S)。背景レイヤーを隠せば透過PNG |

## 非機能要件
- PC優先(マウス・ペンタブ筆圧対応)。タッチでも描画可、ピンチ操作は対象外
- キャンバス既定 1024×768(新規作成で 800×600 / 1024×768 / 1280×720 / 1080×1080)
- 既存ゲームと同じ宇宙テーマの暗色UI

## 主なショートカット
B ペン / E 消しゴム / G 塗り / I スポイト / L 直線 / U 四角 / O 楕円 / M 選択 /
[ ] サイズ / X 色入替 / `,` `.` 回転 / Space+ドラッグ パン / ホイール ズーム / Shift+ホイール 回転 /
Ctrl+Z,Y Undo,Redo / Ctrl+S 保存 / Alt 一時スポイト / Enter 選択確定 / Delete 選択消去
