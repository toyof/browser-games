# Parking Out 要件定義

元ネタのジャンル: Parking Jam 3D / Car Out!(満車の駐車場から車を出す)。名前・見た目・ステージは自作。

## 位置づけ
- `parking/index.html`(静的HTML単体)。ポータルのカード 🅿️ Parking Out
- 保存: `parkingBest` / `parkingCur` / `parkingMute`

## ルール
| 項目 | 内容 |
|---|---|
| 盤面 | 上から見たグリッド。車は2マス、トラックは3マス。縦向きと横向きがある |
| 操作 | タップすると車は前へ走る。スワイプした場合は、その向き(前か後ろ)へ走る |
| 出庫 | 進む先に何もなければ外周の道路へ出て消える |
| 衝突 | 他の車やパイロンに当たると、そこで止まって元の位置へ戻る(盤面は変わらない)。「ぶつけた回数」に数える |
| クリア | 全台出庫。ぶつけた回数 0 で★3、1〜2回で★2、3回以上で★1 |
| 補助 | 最初から / ヒント(今すぐ出られる車と向きを矢印で示す) |

## ステージ
- **自動生成**(ステージ番号が乱数の種)。盤面は 5×6 から始まり、最大 8×10
- ステージ3からパイロン(動かない障害物)を置く。トラックの割合はステージが進むほど増える
- 生成方法: 「置いた時点で外へ出られる車」だけを順に置いていく。逆の順番に出せば必ず全台出せるので、解けない盤面にならない
- 30回試し、「台数 + 最初は前後とも塞がれている台数×2」が最大の配置を採用する
