# Tangle Free 要件定義

元ネタのジャンル: Tangle Master 3D / Twisted Tangle(絡まったロープをほどく)。2D 版として自作。

## 位置づけ
- `tangle/index.html`(静的HTML単体)。ポータルのカード 🪢 Tangle Free
- 保存: `tangleBest` / `tangleCur` / `tangleMute`

## ルール(上下関係あり)
| 項目 | 内容 |
|---|---|
| 盤面 | 穴が格子状に並んだ板。ロープはピン2本で穴に留めてあり、穴と穴の間はまっすぐ張られる |
| 重なり | 各ロープに上下の順番がある。交差点では上のロープが下のロープの上に描かれる |
| 操作 | ピンをドラッグして空いている穴へ移す |
| 制約 | **上に別のロープが乗っているロープのピンは動かせない**(🔒を表示。触ると揺れて知らせる) |
| 動かした後 | 動かしたロープは一番上になる |
| 交差の判定 | 線分同士が交わる場合に加え、ピンが別のロープの上に乗る場合や、一直線に重なる場合も交差とみなす |
| クリア | 交差がゼロ。手数が目安以内で★3、目安+3手以内で★2 |
| 補助 | 戻す / 最初から |

## ステージ
- **自動生成**。ロープ3本・穴3×3 から始まり、最大でロープ7本・穴4×5
- 生成方法: まず交差のない配置を作る。そこから逆再生で、「一番上のロープのピンを動かし、そのロープを交差相手より少しだけ上の高さに戻す」を数回くり返す。順方向に見ると正しい手順になっているので、必ず解ける
- 目安手数は、反復深化探索(探す深さを1手ずつ増やす方法)で求めた最短手数。探索が上限ノード数に達した場合は逆再生の手数を使う
