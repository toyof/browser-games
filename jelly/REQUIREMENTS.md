# Jelly Chain 要件定義

ジャンル: ぷよぷよ系の連鎖落ち物パズル(商標のため名前・見た目は自作)。

## 位置づけ
- `jelly/index.html`(静的HTML単体)。400×700 の canvas を縦長表示。保存: `jellyBest`
- 盤面は6列×12段(+画面外の隠し段1)。ゼリーは4色。落下の速さは時間刻みで、ゲームの結果に乱数以外のブレは無い

## ルール
| 項目 | 内容 |
|---|---|
| ペア | 2個1組が列2(左から3列目)の上から降る。軸+子の向きを回転できる |
| 消去 | 上下左右に同色が4個以上つながると消える。消えた上のゼリーは落ち、また4個以上つながれば連鎖 |
| 得点 | 消した数×10×(連鎖ボーナス+同時消し色数ボーナス+連結ボーナス)。連鎖 8/16/32/64/96/… |
| 速度 | 0.7秒/段から、30個消すごとに0.03秒ずつ速くなる(下限0.12秒)。↓長押しで0.04秒/段 |
| 設置 | 下が塞がってから0.4秒で固定(その間は左右移動・回転で滑り込める) |
| 終了 | 新しいペアが出現位置(✕印)に置けない |
| 回転 | 壁・床に当たると押し戻す。両側が塞がっていたら180度回転(クイックターン) |

## 操作
- スマホ: 下の ◀ ▶ ▼ ⟳ ボタン(長押しリピート可)。主操作の回転は右端。盤面タップでも回転
- PC: ← → ↓、回転は X/↑/Space(右)・Z(左)

## 検証(`window.__game`)
- `resolve(rows)`: 盤面を置いて連鎖を最後まで解く。2連鎖の盤面で score=960(320+640), maxChain=2 / 3個だけなら消えない
- `play(n)`: 乱数で置き続けて破綻なく終了(確認時 83ペアでゲームオーバー)
