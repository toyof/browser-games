# Orbit Hop 要件定義

ジャンル: タイミング系ワンボタン(Orbit 系)。名前・見た目は自作。

## 位置づけ
- `hop/index.html`(静的HTML単体)。400×700 の canvas を縦長表示。保存: `hopBest`(ハイスコア)
- 物理は固定刻み `STEP=1/120`(リフレッシュレートで結果が変わらない)。乱数は seed 付き(`__game.start(seed)`)

## ルール
| 項目 | 内容 |
|---|---|
| 操作 | タップ/クリック/スペースで、いま回っている点を接線方向へ発射 |
| 捕獲 | 飛行中に(直前の惑星以外の)軌道の輪に入ると、その惑星の周回に移る。回転方向は進入方向で決まる |
| 得点 | 一番遠い惑星より1つ先の惑星に乗るたび +1(戻っても加点なし) |
| 速度 | 190 + 4×得点(上限 340)px/s。周回の角速度は 速度/軌道半径 |
| 失敗 | 画面の下/左右の外へ出る、または飛行が4秒を超える |
| 画面 | 左上は共通「← トップへ」ボタン用に空ける。主ボタン(START/RETRY)は右側 |

## 検証(`window.__game`)
- `blind(n)`: 何もしないと失敗しない(周回し続ける) / `fling()`: 適当な連打は失敗する
- `start(1); auto()`: 先読みで発射すれば長く続く(確認時 90秒で 111点)
