# Color Tubes 要件定義

元ネタのジャンル: Water Sort Puzzle(試験管の色水ソート)。名前・見た目・ステージは自作。

## 位置づけ
- `tubes/index.html`(静的HTML単体、ビルド不要)。ポータルのカード 🧪 Color Tubes
- 保存: `tubesBest`(クリアした最高ステージ。ポータルのバッジ)/ `tubesCur`(最後に遊んだステージ)/ `tubesMute`

## ルール
| 項目 | 内容 |
|---|---|
| 操作 | 試験管をタップで選択 → 注ぐ先をタップ |
| 注げる条件 | 注ぐ先が空、または一番上が同じ色で空きがある(一番上の同じ色をまとめて移す) |
| クリア | 全部の試験管が「空」か「4つとも同じ色」 |
| 補助 | 戻す(無制限)/ 最初から / +1本(1ステージ1回)/ ヒント(ソルバーが次の1手を示す。詰みなら知らせる) |

## ステージ
- **自動生成**(ステージ番号を種にした乱数なので、同じステージは毎回同じ配置)
- 色の数 = `min(11, 2 + ceil(stage/2))`、空の試験管は2本、容量は4
- 生成時に深さ優先探索のソルバーで解けることを確認し、解けない配置は捨てる。最初から3つ以上そろった管も避ける
- 全99ステージ

## 画面
- 400×700 の canvas を縦長で表示。試験管が7本以上なら2段に並べる
- 色ごとに記号(●▲■…)を付けて、色の区別がつきにくい人でも遊べるようにする
- 下部のボタンは、主操作の「戻す」を右端に置く
