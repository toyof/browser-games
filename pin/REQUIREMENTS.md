# Pin Flow 要件定義

元ネタのジャンル: Pull the Pin / Hero Rescue(ピンを抜いて水や溶岩の流れを変える)。名前・見た目・ステージは自作。

## 位置づけ
- `pin/index.html`(静的HTML単体)。物理エンジンは使わず、粒子シミュレーションを自作
- 保存: `pinBest` / `pinCur` / `pinMute`

## ルール
| 項目 | 内容 |
|---|---|
| 操作 | ピン(本体か持ち手のリング)をタップすると、持ち手の方向へ抜ける |
| 粒子 | 💎宝石 / 💧水 / 🔥溶岩 / 🪨石 |
| 反応 | 水と溶岩が触れると、溶岩は石になり、水は蒸気になって消える。冷えたばかりの石は、触れている溶岩も連鎖的に石にする(最大8段) |
| 危険 | 溶岩に触れた宝石は燃えて消える |
| クリア | カップの宝石が規定割合(70〜80%)以上で、ほぼ静止した |
| 失敗 | 溶岩がカップに入った/燃えたり落ちたりして宝石が足りなくなった/全部のピンを抜いて静止しても足りない |
| 評価 | カップに入った宝石の割合が90%以上で★3、80%以上で★2 |

## ステージ(全20: 手作り5 + 縦穴型15)
1. ピンを抜こう(1本、チュートリアル)
2. 水で冷やせ(水→溶岩→宝石の順)
3. 流れを変えろ(斜めのピンで溶岩を捨て穴へ流してから、斜めのピンを抜く)
4. 溶岩だまり(途中の棚にある溶岩を、先に水で固める)
5. ぜんぶ使え(4本。冷やす/捨てるの両方が使える)

6〜20は「縦穴の中にドア(ピン)が3〜4枚。各ドアの上の部屋に 宝石/水/溶岩 が入っている」型。
乱数で配置を作り、全順列を `__game.run()` で試して「クリアできる順番が1〜3通りだけ」のものを選んだ(ステージ上部の `sol` が正解の1つ)。
溶岩を水で冷やしてから落とす等のため、ピンの間隔が短いと失敗する(5〜20は間隔120フレーム=2秒で検証。19〜20は180フレーム)。
`need` は各ステージの正解時の歩留まりから少し余裕を引いて決めてある(0.6〜0.8)。

各ステージで正解の順番(`sol`)を持ち、テストで「正解ならクリア/間違った順なら失敗」を全順列について確認済み。

## 粒子シミュレーション
- 位置ベースの方式(粒子を速度で動かし、重なりを押し出し、位置の変化から速度を求める)。1フレームを3回に分けて計算し、押し出しは2回くり返す
- 粒子の半径は5。近くの粒子の探索には12pxの空間ハッシュ(格子で区切り、近くのマスだけ調べる)を使う。壁とピンは太さのある線分として扱う
- 速度の上限は 3.2px/回(すり抜け防止)。溶岩だけ少しねばる(減衰を強める)
- 静止の判定: 速く動いている粒子が全体の2%以下(積み重なった粒子は少し震え続けるため)
