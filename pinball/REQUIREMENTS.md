# Galaxy Pinball 要件定義

- `pinball/index.html`(静的HTML単体)。400×700 の canvas を縦長表示。保存: `pinballBest`。物理は自作・固定刻み `STEP=1/480`(`pin/` の Pin Flow とは別ゲーム)
- 操作: 画面の左半分=左フリッパー / 右半分=右フリッパー(マルチタッチ可)。キーボードは Z/← と / → 、Space で発射
- 発射: 右レーンのボールを長押しでチャージ(0.9秒で最大)→はなして発射。最弱でもアーチに届く速度(960px/s〜)
- 得点: バンパー +100(大3・小2) / スリングショット +10。ボール3つ、落下(場外含む)で1つ減る
- 物理: 重力800px/s²、ボール半径8、速度上限1500。フリッパーは回転の面速度をボールに伝える。2秒以上止まったら軽く揺らす
- 画面: 左上は共通「← トップへ」ボタン用に空ける。START/RETRY は右側
- 検証(`window.__game`): `launchTest(p)` は発射でフィールドに出られる / `mash(sec)` は連打で場外へ抜けず NaN にならない(確認時 60秒で 2620点)
